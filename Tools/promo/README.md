10-28 브레인스토밍(A 물가의 함정 · B 얼마면 될까 · C 확률 · D 어깨 너머 · E 국민연금 · F 하루 한 줄 원칙 · G 토요일 아침 따라 하기)에서

| 장면 | 화면 |
|---|---|
