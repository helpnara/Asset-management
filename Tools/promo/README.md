# 홍보 모션그래픽 (2026-10-10)

블로그 · SNS 에 올릴 **기능 중심 소개 영상**. 1080×1920 세로(릴스 · 쇼츠 · 네이버 블로그 동영상), 42초, 소리 없음.

| 파일 | 무엇 |
|---|---|
| `promo.html` | 영상 자체. 브라우저로 열면 바로 재생된다. 모든 움직임이 `render(t)` 하나에서 나온다 |
| `render.mjs` | `promo.html` 을 1/30초씩 찍어 `out/slowrich-promo.mp4` 로 굽는다 |
| `fonts/` | Pretendard (SIL OFL 1.1 — `Pretendard-LICENSE.txt`) |
| `out/slowrich-promo.mp4` | 구운 결과 — **10-10 판이라 옛 아이콘**이다. 202번 새 아이콘(10-18) 뒤로 다시 굽지 않았다 |
| `whatif.html` · `clips.mjs` | **쇼츠 2편** (10-25) — 아래 |
| `out/slowrich-shorts-whatif.mp4` | 2편 구운 결과 — 1080×1920, 29초, 새 아이콘 · **10-25 유튜브에 올림** (사용자) |
| `habit.html` · `out/slowrich-shorts-habit.mp4` | **쇼츠 3편** (10-27) — 1080×1920, 29.5초 · **10-28 유튜브에 올림** (사용자). 아래 |

```bash
node Tools/promo/render.mjs                    # 영상 굽기 (원격 세션에서 몇 분)
node Tools/promo/render.mjs --stills 3.5,11.5  # 그 초의 한 장만 PNG 로 (확인용)
```

**장면 순서** — 물음("노후 준비, 잘 가고 있나요?") → 앱 아이콘 · 이름 → ① 주간 점검 ② 궤적 ③ 만약에 ④ 자산 진단
⑤ 가족 공유 → 일부러 안 만든 것(서버 · 광고 · 자동 연동) → App Store 안내. 시간표는 `promo.html` 의 `T`.

**앱 화면은 `screenshots/` 를 그대로 읽는다** — CI 가 체험 자료(가상의 가족)로 찍은 것이라 실제 금액이 아니다.
앱 화면이 바뀐 뒤 다시 구우면 새 화면이 들어간다. 아이콘은 `App/Assets.xcassets/AppIcon.appiconset/icon-1024.png`.

**올릴 때** — 음악은 넣지 않았다. 인스타그램 · 유튜브 쇼츠는 앱 안에서 저작권 없는 음악을 고를 수 있다.
마지막 장면에 "입력한 가정에 따른 계산이며 미래 수익을 보장하지 않습니다 · 화면은 가상의 체험 자료" 한 줄이 있다 — 지우지 않는다.

## 쇼츠 2편 — "매달 얼마를 더 넣으면 은퇴 때 얼마가 될까?" (2026-10-25)

1편이 기능 다섯을 차례로 보여 준 42초였다면, 2편은 **물음 하나로 시작해 실제 앱 녹화로 답하는 29초**다.
쇼츠는 첫 2초에 넘길지 정하므로 물음을 맨 앞에 두고, 숫자가 바뀌는 순간을 3초 안에 보여 준다.

| 장면 | 길이 | 화면 |
|---|---|---|
| 물음 — 매달 얼마를 더 넣으면 / 은퇴 때 얼마가 될까? | 2.9초 | 짙은 숲색 |
| 손잡이를 끌면, 바로 | 6.3초 | **시뮬레이션 녹화** — 월 적립 410만 → 670만원, 2049년 예상 61.9억 → 87.7억. 카드 `매달 260만원을 더 넣으면 은퇴 때 +25.8억` |
| 목표에 언제 닿을지까지 | 6.2초 | 궤적 크게 보기 스크린샷(`screenshots/36`) — 목표선 · 목표에 닿는 해 · 은퇴 때에 차례로 테두리 |
| 매주 토요일, 3분이면 끝 | 5.8초 | **주간 점검 녹화** — 적자마자 뜨는 지난주 대비 증감에 테두리 |
| 일부러 안 만들었습니다 | 3.0초 | 서버 · 광고 / 회원가입 / 잔고 자동 연동 |
| 마무리 | 4.8초 | 새 아이콘 · App Store 에서 ‘느린 부자’ · 무료 · 계산 · 체험 자료 안내 |

```bash
node Tools/promo/clips.mjs                                                        # 녹화 구간을 그림으로 (커밋 안 함)
node Tools/promo/render.mjs --page whatif.html --out slowrich-shorts-whatif.mp4   # 굽기 (원격 세션에서 2분쯤)
node Tools/promo/render.mjs --page whatif.html --stills 6.2,12.5                  # 확인용 한 장
```

- **녹화는 App Store 미리 보기 녹화**(`Tools/preview/raw`, 10-12, 체험 자료)를 다시 쓴다. 시뮬레이션은 손잡이를 끈 뒤
  `반영 중` 으로 4초 멈춰 있어 **그 사이를 잘라 냈다**(`clips.mjs` 의 `keep`). 구간은 그림을 6장마다 훑어 골랐다 — 녹화가 가변 프레임이라
  초로 짐작하면 어긋난다(1편 미리 보기 때와 같은 일).
- 테두리 · 표시는 그림 위 좌표로 얹는다. **확대 움직임을 주지 않는다** — 화면이 커지면 테두리가 글씨에서 어긋났다(첫 시안).
  점검 장면의 테두리는 적던 칸이 다음 칸으로 넘어가 줄이 밀리기(2.67초) 전에 걷는다.
- 숫자는 모두 체험 자료(가상의 가족)다. 마지막 장면의 안내 두 줄은 지우지 않는다.
- 녹화는 10-12 판 앱이라 시뮬레이션 화면 모양이 지금과 조금 다를 수 있다. 앱 화면이 크게 바뀌면 미리 보기 녹화부터 다시 한다.

## 쇼츠 3편 — "노후 준비, 1년에 52번 들여다보면" (2026-10-27)

1편은 기능 다섯, 2편은 시뮬레이션 녹화로 "얼마가 될까". 3편은 **쌓이는 기록**이다 — 토요일 3분이 한 주 → 한 달 → 가족 → A4 한 장으로 모인다.
녹화를 쓰지 않고 **CI 가 찍은 지금 판 스크린샷**(체험 자료)만 쓴다 — 1.0.12 화면 그대로라 2편처럼 옛 화면이 섞이지 않는다.

| 장면 | 길이 | 화면 (screenshots/) | 테두리 |
|---|---|---|---|
| 물음 — 노후 준비, / 1년에 52번 들여다보면 | 3.0초 | 짙은 숲색 | |
| 토요일마다 3분 | 5.6초 | `05-review-done` 점검 완료 | 이번 주 변화 · 연속 기록 · 구성원별 |
| 한 달이 모이면 | 5.6초 | `23-retrospective` 회고(월간 · 연간) | 이번 달 · 넣은 돈 · 자란 돈 · 이정표 |
| 가족 넷이 함께 | 5.4초 | `15-family-allocation` 가족 자산 배분 | 구성원별 비중 · 국가 배분 |
| 1년이면 A4 한 장 계획서 | 5.2초 | `16-one-pager` 1페이지 미리보기 | `PDF로 저장 · 인쇄` |
| 마무리 | 4.7초 | 새 아이콘 · 느리게, 그래도 꾸준히 · 무료 · 서버 · 광고 · 회원가입 없음 · 안내 두 줄 | |

```bash
node Tools/promo/render.mjs --page habit.html --out slowrich-shorts-habit.mp4   # 원격 세션에서 2분쯤
```

- 테두리 좌표는 스크린샷(1206 폭)을 창(940 폭, ×0.779)으로 옮긴 값이다. **CI 스크린샷이 바뀌면 다시 맞춘다** — `--stills` 로 한 장씩 보고.
- 창 맨 위에 뒤로가기 줄이 반쯤 걸리면 지저분해서, 회고 · 가족 배분은 제목 줄 아래부터 보여 준다(첫 시안에서 고침).
- 화면마다 체험 자료의 시점이 달라 금액이 서로 다르다(점검 완료 2억 4,028만 · 가족 배분 3억 1,250만). 그래서 **금액에는 테두리를 두르지 않고** 이름 · 비율 · 구성에 두른다 — 이번 주 변화(+53만) · 이번 달(+172만)만 예외로, 한 화면 안에서 맞는 값이다.
