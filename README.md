# 느린 부자 — iPhone 앱

매주 토요일 가족 자산을 직접 적어 넣고, 그 숫자가 **계획선 위에 있는지 아래에 있는지**를
은퇴 시점까지 이어지는 하나의 궤적으로 확인하는 iOS 앱입니다.
서버 없이 기기와 개인 iCloud에만 데이터를 저장합니다.

출발점은 이미 손으로 만들어 쓰고 있는 **A4 1페이지 계획서**입니다.
이 앱의 목표는 그 1페이지를 살아 움직이게 만드는 것입니다.
(→ [1페이지 구조 분석](docs/reference/one-pager-analysis.md))

| 항목 | 결정 |
|---|---|
| 플랫폼 | iOS 17+ · iPhone · iPad (가로 좌측 메뉴까지, [M7](docs/05-roadmap.md)) |
| UI | SwiftUI + Swift Charts |
| 영속성 | **Core Data** + CloudKit (개인 · 가족 공유 데이터베이스). SwiftData 로 시작했다가 가족 공유 때문에 옮겼다 ([ADR-0001](docs/adr/0001-swiftdata-cloudkit.md)) |
| 백엔드 | 없음. 아웃바운드 네트워크 요청이 하나도 없다 |
| 데이터 입력 | 전부 수동. 매주 토요일 알림 → 3분 점검 ([ADR-0005](docs/adr/0005-manual-entry.md)) |
| 기준 통화 | **원화 하나.** 해외 종목도 원화로 환산해서 적는다 ([ADR-0005](docs/adr/0005-manual-entry.md)) |

## 지금 무엇이 만들어져 있나 (2026-09-27)

**1.0 을 가족 넷이 TestFlight 로 쓰고 있습니다** (빌드 115). 안정화 기준을 채우면
App Store 에 무료로 냅니다 — 10월 하순 예정 ([로드맵](docs/05-roadmap.md)).

다섯 탭과 그 아래 화면들이 전부 동작합니다.

| 탭 | 하는 일 |
|---|---|
| **현황판** | 오늘의 운용 원칙 · 목·실·감 · 이번 주 점검 · 챙길 것 · 로드맵 · 가족 총자산 · 넣은 돈/자란 돈 · 지난달 회고 · 궤적 · 진단 요약 · 구성원 (카드 순서는 바꿀 수 있다) |
| **자산** | 구성원 → 계좌 → 종목 3단 입력. 상장국가·입력주기·목표 비중·PFIC 경고·종목 "왜 샀나" 이력 |
| **계획** | 적립(구성원별 배분) · 기대수익률 · 물가 · 목표 · 목돈 이벤트 · **은퇴 후 생활비와 연금** · 국민연금 추정 |
| **시뮬레이션** | 손잡이 여섯 What-if · 몬테카를로 신뢰구간 · 목표 도달 확률 · 시나리오 저장 |
| **더보기** | 회고 · 자산 진단 · 변경 이력 · 지난 기록 · 운용 원칙 · 마일스톤 · 챙길 것 · 내보내기 · 알림 · 잠금 · **가족 공유** · 동기화 · 도움말 |

핵심 계산은 전부 `Packages/Core`(순수 Swift)에 있고 **테스트로 덮여 있습니다.**
숫자 기댓값은 한 번도 손으로 짐작하지 않았습니다 — 전부 파이썬으로 따로 굴려 대조했습니다.

- 순자산 궤적(적립 → 은퇴 → **인출**), 자산 고갈 시점
- 몬테카를로 신뢰구간 (시드 고정 SplitMix64 + Box–Muller)
- 자산 진단 일곱 규칙 (4% 규칙 · 부동산 비중 · 국가 배분 · 세제혜택 계좌 순서 · 선저축 · 목표 비중 · 월세 적정성)
- 금액은 정수 `Money`, 반올림은 한 곳에서만 ([ADR-0003](docs/adr/0003-money-representation.md))

화면은 매 푸시마다 CI가 시뮬레이터에서 찍어 [`screenshots/`](screenshots/)에 되돌려 커밋합니다.

## 종이 계획서와 무엇이 다른가

| 종이의 한계 | 앱의 답 |
|---|---|
| 갱신할 계기가 없다 | 매주 토요일 알림 → 탭하면 바로 입력 화면 |
| 적어도 아무 일이 안 일어난다 | 입력이 끝나면 계획 대비 실적과 연속 기록이 즉시 뜬다 |
| "만약에"를 못 해본다 | What-if 슬라이더로 즉시 재계산, 시나리오로 저장 |
| 계획과 실제를 겹쳐 볼 수 없다 | 주간 스냅샷 → 계획선 대비 실제선 |
| 원칙 위반을 사람이 찾아야 한다 | 자산 진단 일곱 규칙이 매번 다시 판정 |
| 기한을 놓친다 | 챙길 것 + 30일 전 · 당일 알림, 계좌 만기 알림 |
| 은퇴 이후가 비어 있다 | 연금과 생활비를 넣으면 인출 구간과 **고갈 시점**까지 그린다 |
| 갱신하려면 다시 만들어야 한다 | 1페이지 PDF 를 언제든 다시 뽑는다 |

## 개인정보에 관한 원칙

이 저장소에는 **실제 금액·기관명·계좌 정보를 커밋하지 않습니다.**
문서의 모든 숫자는 구조 설명을 위한 예시이며, 테스트 픽스처도 가상 데이터를 씁니다.

앱 자체도 같은 원칙입니다. 아웃바운드 네트워크 요청이 하나도 없고, 분석 도구도 없으며,
자료는 기기와 **사용자 본인의 iCloud**에만 있습니다. 개발자도 볼 수 없습니다.
