# 느린 부자의 기록 — iPhone 앱

매주 토요일 가족 자산을 직접 적어 넣고, 그 숫자가 **계획선 위에 있는지 아래에 있는지**를
은퇴 시점까지 이어지는 하나의 궤적으로 확인하는 iOS 앱입니다.
서버 없이 기기와 개인 iCloud에만 데이터를 저장합니다.

출발점은 이미 손으로 만들어 쓰고 있는 **A4 1페이지 계획서**입니다.
이 앱의 목표는 그 1페이지를 살아 움직이게 만드는 것입니다.
(→ [1페이지 구조 분석](docs/reference/one-pager-analysis.md))

| 항목 | 결정 |
|---|---|
| 플랫폼 | iOS 17+ (iPhone 우선) |
| UI | SwiftUI + Swift Charts |
| 영속성 | SwiftData + CloudKit private database |
| 백엔드 | 없음. 아웃바운드 네트워크 요청이 하나도 없다 |
| 데이터 입력 | 전부 수동. 매주 토요일 알림 → 3분 점검 ([ADR-0005](docs/adr/0005-manual-entry.md)) |
| 기준 통화 | 사용자 설정 (기본 KRW), 다중 통화 지원 |

## 종이 계획서와 무엇이 다른가

| 종이의 한계 | 앱의 답 |
|---|---|
| 갱신할 계기가 없다 | 매주 토요일 알림 → 탭하면 바로 입력 화면 |
| 적어도 아무 일이 안 일어난다 | 입력이 끝나면 계획 대비 실적과 연속 기록이 즉시 뜬다 |
| "만약에"를 못 해본다 | What-if 슬라이더로 즉시 재계산 |
| 계획과 실제를 겹쳐 볼 수 없다 | 주간 스냅샷 → 계획선 대비 실제선 |
| 원칙 위반을 사람이 찾아야 한다 | 비중 상한·지역 배분·세적 제약 자동 점검 |
| 기한을 놓친다 | 증여 신고·만기·정기 점검 알림 |
| 갱신하려면 다시 만들어야 한다 | 입력하면 1페이지가 자동으로 다시 그려진다 |

## 개인정보에 관한 원칙

이 저장소에는 **실제 금액·기관명·계좌 정보를 커밋하지 않습니다.**
문서의 모든 숫자는 구조 설명을 위한 예시이며, 테스트 픽스처도 가상 데이터를 씁니다.

## 화면 목업

10개 화면 목업을 디자인 캔버스로 만들어 두었습니다 —
현황판 · 구성원 상세 · 자산 목록 · **토요일 알림 → 주간 점검 → 점검 완료** · 계획 · 시뮬레이션 ·
원칙과 점검 · 디자인 토큰. 색과 활자는 기존 1페이지 PDF에서 그대로 뽑았습니다.
