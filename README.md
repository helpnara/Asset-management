# 우리 가족 노후자금 준비 — iPhone 앱

가족 구성원별 자산을 모아 **지금까지 얼마나 모았고, 이대로 가면 은퇴 시점에 얼마가 되는지**를
한 화면에서 보여주는 iOS 앱입니다. 서버 없이 기기와 개인 iCloud에만 데이터를 저장합니다.

출발점은 이미 손으로 만들어 쓰고 있는 **A4 1페이지 계획서**입니다.
이 앱의 목표는 그 1페이지를 살아 움직이게 만드는 것입니다.
(→ [1페이지 구조 분석](docs/reference/one-pager-analysis.md))

| 항목 | 결정 |
|---|---|
| 플랫폼 | iOS 17+ (iPhone 우선) |
| UI | SwiftUI + Swift Charts |
| 영속성 | SwiftData + CloudKit private database |
| 백엔드 | 없음. 외부 요청은 시세·환율 조회뿐 |
| 기준 통화 | 사용자 설정 (기본 KRW), 다중 통화 지원 |

## 종이 계획서와 무엇이 다른가

| 종이의 한계 | 앱의 답 |
|---|---|
| 만든 순간부터 낡는다 | 시세·환율 자동 갱신, 궤적 자동 재계산 |
| "만약에"를 못 해본다 | What-if 슬라이더로 즉시 재계산 |
| 계획과 실제를 겹쳐 볼 수 없다 | 매일 스냅샷 → 계획선 대비 실제선 |
| 원칙 위반을 사람이 찾아야 한다 | 비중 상한·지역 배분·세적 제약 자동 점검 |
| 기한을 놓친다 | 증여 신고·만기·정기 점검 알림 |
| 갱신하려면 다시 만들어야 한다 | 입력하면 1페이지가 자동으로 다시 그려진다 |
