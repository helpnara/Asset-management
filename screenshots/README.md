# 시뮬레이터 스크린샷

이 디렉터리의 PNG는 **사람이 넣지 않습니다.** GitHub Actions의 macOS 러너가
푸시할 때마다 앱을 빌드하고 시뮬레이터에서 찍어 되돌려 커밋합니다
(`.github/workflows/ios.yml`).

원격 Linux 세션에서는 iOS 앱을 빌드할 수 없기 때문에, 이 파일들이
"지금 앱이 실제로 어떻게 보이는가"를 확인하는 유일한 창구입니다.

파일명은 `NN-화면이름.png` 규칙을 씁니다. 번호는 앱을 처음 켠 순서를 따릅니다
(`00-welcome` → `01-empty` → 탭 순서). 화면이 하나 끼어들면 번호는 다시 매깁니다.

## `dark/`

같은 화면을 **다크 모드**로 찍은 것입니다. 라이트로만 찍다가 화면마다 톤이
제각각인 것을 놓친 적이 있어 추가했습니다 (docs/08-feedback.md 1번).

라이트와 다크를 나란히 놓고 **글자가 읽히는지, 바탕이 화면마다 튀지 않는지**를
봅니다. 톤이 갈리던 화면만 찍습니다 — 전부 찍으면 커밋이 두 배로 무거워집니다.

## `ipad/`

같은 `ios.yml` 이 아이패드 시뮬레이터로 찍은 몇 화면입니다 (현황판 · 자산 · 계획 · 시뮬레이션 · 더보기 · 진단 …).

## `appstore/`

**푸시마다 찍지 않습니다.** `Actions → App Store 스크린샷`(`.github/workflows/appstore-screenshots.yml`)을
손으로 돌릴 때만 바뀝니다. `iphone/` · `ipad/` 가 원본이고, `store/` 아래가 문장을 얹은 제출용입니다 —
`store/iphone-6.5/`(1284×2778) · `store/iphone-6.3/`(1206×2622, 15.5 · 15.9cm 칸) · `store/ipad/`(2064×2752).
규격은 [docs/07 4단계](../docs/07-app-store.md#4단계--스크린샷).
