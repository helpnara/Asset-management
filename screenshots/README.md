# 시뮬레이터 스크린샷

이 디렉터리의 PNG는 **사람이 넣지 않습니다.** GitHub Actions의 macOS 러너가
푸시할 때마다 앱을 빌드하고 시뮬레이터에서 찍어 되돌려 커밋합니다
(`.github/workflows/ios.yml`).

원격 Linux 세션에서는 iOS 앱을 빌드할 수 없기 때문에, 이 파일들이
"지금 앱이 실제로 어떻게 보이는가"를 확인하는 유일한 창구입니다.

파일명은 `NN-화면이름.png` 규칙을 씁니다. 번호는 앱을 처음 켠 순서를 따릅니다
(`00-welcome` → `01-empty` → 탭 순서). 화면이 하나 끼어들면 번호는 다시 매깁니다.
