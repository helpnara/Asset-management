# 개인정보 처리방침 — 느린 부자의 기록

최종 수정일: 2026년 9월 5일

## 한 줄 요약

**이 앱은 어떤 개인정보도 수집하거나 외부로 보내지 않습니다.**
입력한 자료는 사용자의 기기와 사용자 본인의 iCloud 계정에만 저장됩니다.

## 1. 수집하는 정보

**없습니다.**

이 앱에는 서버가 없습니다. 개발자가 운영하는 어떤 시스템으로도 자료가
전송되지 않습니다. 회원가입, 로그인, 이메일 입력이 없습니다.

## 2. 앱이 저장하는 것

사용자가 직접 입력한 다음 자료가 **기기 안에** 저장됩니다.

- 가족 구성원의 이름·생년월·세적 구분
- 계좌 이름·금융기관 이름·계좌 종류
- 보유 종목 이름·평가액·자산군·상장 국가
- 주간 점검 기록과 계획 가정(적립액, 기대수익률 등)
- 유의사항·할 일·마일스톤 메모

## 3. iCloud 동기화

사용자가 iCloud에 로그인해 두면, 위 자료가 **사용자 본인의 iCloud
개인 데이터베이스(private database)** 에 저장되어 기기 간에 동기화됩니다.

- 이 영역은 **사용자의 Apple 계정에 속합니다**
- **개발자는 접근할 수 없습니다.** 애플도 내용을 읽을 수 없습니다
- 동기화를 원하지 않으면 iOS 설정에서 이 앱의 iCloud를 끄면 됩니다

iCloud에 저장된 자료의 처리는 [애플의 개인정보 처리방침](https://www.apple.com/legal/privacy/kr/)을
따릅니다.

## 4. 외부 통신

**이 앱은 인터넷으로 어떤 요청도 보내지 않습니다.**

- 주가·시세를 가져오지 않습니다 (모든 평가액은 사용자가 직접 입력)
- 환율을 가져오지 않습니다 (모든 금액은 원화로 입력)
- 분석 도구(Analytics), 광고, 크래시 리포터를 쓰지 않습니다
- 제3자 SDK를 포함하지 않습니다

유일한 네트워크 활동은 **애플이 제공하는 iCloud 동기화**이며, 이는 운영체제가
직접 수행합니다.

## 5. 알림

주간 점검 알림과 기한 알림은 **기기 안에서 예약되는 로컬 알림**입니다.
푸시 서버를 거치지 않으며, 알림 내용이 외부로 나가지 않습니다.

알림에 금액을 표시할지는 앱 안에서 끄고 켤 수 있으며, 기본값은 **표시하지 않음**입니다.

## 6. 사용자의 권리

| 하고 싶은 것 | 방법 |
|---|---|
| 자료를 보고 싶다 | 앱 안에서 언제든 |
| 자료를 내보내고 싶다 | 더보기 → 1페이지 · 백업 내보내기 (CSV) |
| 자료를 지우고 싶다 | 앱을 삭제하면 기기의 자료가 지워집니다 |
| iCloud의 자료도 지우고 싶다 | iOS 설정 → Apple 계정 → iCloud → 저장 공간 관리 → 이 앱 → 데이터 삭제 |

개발자에게 삭제를 요청할 필요가 없습니다. **개발자는 애초에 자료를 가지고 있지 않습니다.**

## 7. 아동

이 앱은 가족의 자산을 기록하며 여기에 자녀의 이름이 포함될 수 있습니다.
그 정보 역시 기기와 사용자 본인의 iCloud를 벗어나지 않습니다.
아동으로부터 직접 정보를 수집하지 않습니다.

## 8. 투자에 관한 고지

이 앱의 모든 예측과 진단은 **사용자가 입력한 가정에 따른 계산**이며
미래의 수익을 보장하지 않습니다. 이 앱은 금융 상품을 추천하거나 중개하지 않고,
투자 자문을 제공하지 않습니다.

## 9. 변경

이 방침이 바뀌면 이 페이지를 갱신하고 최종 수정일을 고칩니다.
수집 항목이 생기는 변경은 앱 업데이트 안에서 별도로 안내합니다.
