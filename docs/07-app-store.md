# 7. App Store 출시 — 심사 통과까지

TestFlight는 초대한 사람만 씁니다. **App Store에 올리면 누구나 검색해서 받을 수 있습니다.**

TestFlight까지 왔다면 기술적인 준비는 대부분 끝났습니다.
남은 것은 **심사에 필요한 자료를 채우는 일**이고, 대부분 글쓰기입니다.

> 서두를 이유는 없습니다. 몇 달 직접 써 보고 화면이 안정된 뒤에 올리는 편이
> 낫습니다. 심사에서 반려되면 고쳐서 다시 내면 되지만, 출시한 뒤 바꾸는 것보다
> 출시 전에 다듬는 쪽이 훨씬 쌉니다.

## 0단계 · 먼저 정할 것

| 질문 | 이 앱의 답 |
|---|---|
| 유료인가 무료인가 | **무료.** 결제가 없으면 심사가 훨씬 단순합니다 |
| 계정 로그인이 있나 | 없음. 이게 심사에서 유리합니다 (데모 계정을 안 줘도 됨) |
| 광고·분석이 있나 | 없음. 개인정보 라벨이 `데이터를 수집하지 않음` 하나로 끝납니다 |
| 어느 나라에 낼 것인가 | 한국만으로 시작해도 됩니다. 나중에 넓힐 수 있습니다 |

## 1단계 · 개인정보 처리방침 URL (필수)

**모든 앱에 필수입니다.** 데이터를 안 모으는 앱도 예외가 아닙니다.

방침 본문은 이미 저장소에 있습니다 → [`docs/privacy-policy.md`](privacy-policy.md)

이걸 **웹 주소로** 만들어야 합니다. GitHub Pages가 가장 쉽습니다.

1. <https://github.com/helpnara/Asset-management/settings/pages>
2. **Source** → `Deploy from a branch`
3. **Branch** → `main` (또는 기본 브랜치) / **폴더** → `/docs`
4. **Save**

몇 분 뒤 이 주소가 살아납니다:

```
https://helpnara.github.io/Asset-management/privacy-policy
```

> ⚠️ **저장소가 비공개면 GitHub Pages가 안 됩니다** (무료 플랜 기준).
> 공개하기 싫으면 Notion 공개 페이지, Google Docs 게시, 개인 블로그 등 아무거나
> 됩니다. 애플은 **누구나 열 수 있는 URL** 이기만 하면 됩니다.

| 카테고리 | **금융** (2차: 생산성) |
| 콘텐츠 권한 | 해당 없음 |

### 연령 등급

**앱 정보 → 연령 등급 → 편집**

전부 `없음`으로 답하면 **4+** 가 나옵니다. 이 앱은 폭력·도박·성적 내용이 전혀
없습니다. 다만 하나만 주의:

- **무제한 웹 접근** → 아니요 (웹뷰가 없습니다)
- **도박** → 아니요 (**투자 시뮬레이션은 도박이 아닙니다**)

## 3단계 · 개인정보 라벨 (Nutrition Label)

App Store Connect → 앱 → **App 개인정보 보호** → **시작하기**

**"이 앱이 데이터를 수집합니까?"** → **아니요**

이 앱은 진짜로 아무것도 수집하지 않습니다. 근거:

- 아웃바운드 네트워크 요청이 **하나도 없습니다** (시세·환율도 직접 입력)
- 분석 SDK·광고 SDK가 없습니다
- 자료는 기기와 **사용자 본인의 iCloud 개인 데이터베이스**에만 있습니다.
  개발자는 접근할 수 없습니다

> iCloud에 저장하는 것은 "개발자가 수집하는 것"이 아닙니다. 애플의 기준에서도
> **사용자 본인의 iCloud는 수집에 해당하지 않습니다.** 자신 있게 "아니요"로 답하세요.

`PrivacyInfo.xcprivacy` 도 같은 내용으로 이미 들어 있습니다
(`NSPrivacyTracking: false`, 수집 항목 없음, UserDefaults 사용 사유 `CA92.1`).

## 3-1단계 · 앱 아이콘

`Tools/icon-source.png` 를 App Store 규격(1024×1024, RGB, 알파 없음)으로 구워
`App/Assets.xcassets/AppIcon.appiconset/icon-1024.png` 에 넣습니다.

```bash
pip install pillow
python3 Tools/make-icon.py        # 원본 → 아이콘
python3 Tools/preview-icon.py     # 실제 크기(180·120·60px)로 확인
```

아이콘을 바꾸려면 `Tools/icon-source.png` 를 갈아 끼우고 다시 돌립니다.
**원본을 저장소에 두는 이유는, 결과물만 있으면 나중에 손볼 수 없기 때문입니다.**

### 원본 이미지를 고를 때

홈 화면에서 아이콘은 **60pt** 로 그려집니다. 그 크기에서 죽는 것들이 있습니다.

| 죽는 것 | 왜 |
|---|---|
| 글자 | 한글은 60pt 에서 읽히지 않습니다. Apple HIG 가 아이콘에 글자를 넣지 말라고 못 박습니다. 넣는다면 '읽는 글'이 아니라 '무늬'로 여기세요 |
| 사진의 잔 디테일 | 질감·작은 사물은 뭉갭니다. 큰 색 덩어리만 남습니다 |
| 안에 그린 원·테두리 | iOS 가 이미 모서리를 깎습니다. 안에 또 원을 그리면 네 귀퉁이가 어중간하게 남아 '스티커'처럼 보입니다 |
| 실존 저작물 | 알아볼 수 있는 책 표지·로고가 들어가면 상표·저작권 문제가 될 수 있습니다 |

`preview-icon.py` 로 **반드시 작은 크기를 먼저 보세요.** 큰 화면에서 예뻐 보이는
것과 홈 화면에서 읽히는 것은 다른 문제입니다.

**App Store 가 반려하는 조건 둘:**
- 알파 채널이 있으면 안 됩니다 (스크립트가 `assert` 로 막습니다)
- 모서리를 직접 둥글게 깎으면 안 됩니다 — iOS 가 알아서 합니다

## 4단계 · 스크린샷

**필수는 6.9" 아이폰 한 종류**입니다 (iPhone 16/17 Pro Max 계열, 1320×2868).

최소 3장, 최대 10장. 순서가 곧 App Store에서 보이는 순서입니다.

**(b) 내 아이폰에서 찍기**

단, **실제 금액이 그대로 노출됩니다** — 반드시 `더보기 → 잠금 · 가리기 → 금액 가리기`를
켜고 찍거나, 가상 데이터를 넣어 찍으세요.

### 추천 순서 (3~5장)

1. **현황판** — 총자산과 궤적이 한 화면에
2. **주간 점검** — 이 앱의 핵심 루틴
3. **시뮬레이션** — 신뢰구간 밴드
4. **자산 진단** — 여섯 규칙
5. **계획** — 은퇴 후 소득과 고갈 시점

## 5단계 · 설명문

### 프로모션 텍스트 (170자, 심사 없이 언제든 수정 가능)

```
매주 토요일, 가족 자산을 직접 적습니다. 그 숫자가 은퇴 계획선 위인지 아래인지
하나의 궤적으로 보여 줍니다. 시세를 가져오지 않습니다 — 손으로 적는 그 수고가
계획 대비 실적을 체감하게 합니다.
```

### 설명 (4000자, 수정하려면 심사 필요)

```
느린 부자의 기록은 가족의 노후 준비를 하나의 궤적으로 보는 앱입니다.

■ 매주 토요일, 3분
정한 요일과 시각에 알림이 옵니다. 종목별로 이번 주 평가액을 적어 넣으면
지난주 대비 증감이 바로 보입니다. 알림에서 총액만 먼저 적고 넘어갈 수도 있습니다.

■ 은퇴까지 이어지는 하나의 선
적어 넣은 기록(실선)과 계획에 따른 예측(점선)을 같은 축 위에 그립니다.
계획선 위에 있는지 아래에 있는지 한눈에 보입니다.

■ 은퇴 이후까지
은퇴 후 생활비와 연금(국민연금·퇴직연금·개인연금)을 넣으면 인출 구간까지
이어 그립니다. 자산이 언제 바닥나는지, 혹은 바닥나지 않는지 보여 줍니다.

■ 만약에
월 적립액·은퇴 연도·기대수익률·변동성을 손잡이로 돌려 봅니다. 몬테카를로
1,000경로로 신뢰구간과 목표 도달 확률을 냅니다. 마음에 든 조합은 저장해 둡니다.

■ 자산 진단
· 은퇴 필요 자금 (4% 규칙)
· 부동산 비중 상한
· 국가 배분 (목표는 직접 정합니다)
· 세제혜택 계좌 채우는 순서
· 자산이 두 배 되는 시점 (72의 법칙)
· 선저축 비율
기준은 전부 사용자가 바꿉니다. 기본값은 널리 쓰이는 수치일 뿐 정답이 아닙니다.

■ 시세를 가져오지 않습니다
의도된 설계입니다. 손으로 적는 그 수고가 계획 대비 실적을 체감하게 합니다.
자동으로 갱신되면 지난주와 이번주 사이의 증감에 내가 하지 않은 변화가 섞입니다.
모든 금액은 원화로 적습니다 — 해외 종목도 원화로 환산해서 넣습니다.

■ 자료는 내 것입니다
서버가 없습니다. 외부로 나가는 통신이 하나도 없습니다. 분석 도구도, 광고도
없습니다. 자료는 기기와 본인의 iCloud에만 있습니다. 개발자도 볼 수 없습니다.
Face ID 잠금과 금액 가리기, CSV 백업을 지원합니다.

■ 투자 권유가 아닙니다
모든 계산은 사용자가 입력한 가정에 따른 것이며 미래 수익을 보장하지 않습니다.
이 앱은 금융 상품을 추천하거나 중개하지 않습니다.
```

## 7단계 · 제출

1. **App Store** 탭 → 왼쪽 버전 (`1.0 출시 준비 중`)
2. **빌드** 섹션 → **+** → TestFlight에 올라간 빌드 선택
3. 위에서 채운 것들이 다 초록불인지 확인
4. 오른쪽 위 **심사를 위해 제출**

**심사는 보통 24~48시간**입니다. 결과는 이메일로 옵니다.

## 버전 번호 규칙

`project.yml` 의 `MARKETING_VERSION` 이 App Store에 보이는 버전입니다.

- **빌드 번호**는 GitHub 실행 번호가 자동으로 붙습니다 (손댈 필요 없음)
- **같은 버전 번호로 두 번 심사를 낼 수 없습니다.** 반려되어 고쳤다면
  빌드만 새로 올리면 되고, 출시된 뒤 고쳤다면 `1.0.0` → `1.0.1` 로 올립니다
