# 14. 매일 점검 루틴 — 쓰는 화면 밖의 버그를 찾으려고

2026-09-29 에 시작했다. 사용자의 말 — *"내가 테스트하는 동안 사실 주간입력과
목실감만 쓰다 보니 추가 오류를 확인하기 어려운데 매일 체크해 보면 좋을 것들을
추천해 주면 어때?"* — 에 Claude 가 제안한 방식을 사용자가 받아들였다. **이
과정도 경험치이므로 근거를 남긴다** (사용자).

## 왜 필요한가

안정화 기준 3 · 4(자료 어긋남 없음 · 크래시 0, [로드맵](05-roadmap.md))는 **"4주 동안
아무 일도 없었다"** 로 채워진다. 그런데 매일 쓰는 화면이 주간 점검과 목·실·감 둘뿐이면,
나머지 화면에서는 버그가 있어도 **안 일어난 것처럼 보인다.** 기준은 차는데 제출 뒤
남이 처음 여는 화면에서 터진다.

실제로 그랬다. 189번(편집 화면에서 지우거나 새로 만들고 취소하면 죽음)은 계획 탭의
목돈 이벤트를 **평소에 안 지우다가** 188번 확인 중에 처음 눌러 드러났다. 그 크래시로
기준 4 의 시계가 10-17 에서 10-24 로 밀렸다. 한 번도 안 연 화면은 4주가 지나도 검사된 것이
아니다.

- **"어느 화면 → 무엇을 눌렀더니 → 무엇이 이상했다"** 한 줄. 스크린샷이 있으면 더 좋다.

  `SlowRich-…` 로그 ([12 교훈](12-lessons-learned.md) — 로그 없이 추측하지 않는다).

- Claude 는 받은 것을 [08 피드백](08-feedback.md) 에 번호를 매겨 적고 로드맵 동결 표에
  올린다. 자료가 사라지거나 어긋나는 것만 바로 고치고, 나머지는 "착수하자" 때 묶는다.

### 결론 (2026-11-02 사용자 답)

*"루틴을 수행하면서 보다는 매일 사용하면서 이것저것 눌러보면서 피드백을 주로 준 것이 대부분이야. 실제로 사용하면서
이것저것 체크를 하고 있어. 이슈가 있으면 여기에 올리는 것이라고 보면 돼."*

- **실제 발견 경로는 요일표가 아니라 "매일 쓰면서 이것저것 눌러 보기" 였다.** 아래 표의 `사용자가 쓰다가` 4건과 아이패드 3건이 그것이다.
  요일 영역 0건은 화면이 멀쩡해서라기보다 **표대로 돌지 않았기 때문**이다 — 그래서 이 표로 영역별 값을 매기지 않는다.
- 그래도 루틴 문서는 값을 했다 — **9월 말에 "안 쓰는 화면도 연다" 는 습관을 만든 계기**였고, 그 습관이 남아 이것저것 누르는 사용이 됐다.
  날짜 경계 표는 실제로 그날 맞춰 봤다(10-01 · 10-04 · 11-01).
- **앞으로**: 요일표는 따라야 할 일정이 아니라 "한동안 안 누른 곳" 을 떠올리는 **목록**으로 둔다. 날짜 경계는 지금처럼 그날 본다.
  찾은 것은 지금처럼 바로 가져오면 Claude 가 08 · 동결 표에 적는다 — `기록` 표에 "어디서" 를 따로 적게 하지 않는다(가릴 일이 없다).
- 12 교훈의 해당 절에 한 줄로 옮겼다.

### 초안 (2026-11-02, Claude — 위 결론으로 검토됨)

**센 범위**: App Store 공개 10-07 ~ 11-01. 숫자는 아래 명령으로 센 것만 적는다.

```bash
# 위 `기록` 표의 줄 수 · 그중 10-07 뒤 (11-01 줄을 더하기 전에 셌다: 2 · 1)
awk '/^## 기록/{f=1} /^### 날짜 경계 확인/{f=0} f' docs/14-daily-test-routine.md | grep -c "^| [0-9][0-9]-[0-9][0-9]"
# 08 피드백에 10-07 뒤 접수된 항목 (194~213) · 그중 제목에 아이패드
grep -cE "^## .* (19[4-9]|20[0-9]|21[0-3])\. " docs/08-feedback.md                       # 20
grep -E "^## .* (19[4-9]|20[0-9]|21[0-3])\. " docs/08-feedback.md | grep -c "아이패드"   # 3
```

**1. 루틴 이름으로 적힌 것은 거의 없다.** `기록` 표는 이 초안 전까지 2줄이었고 10-07 뒤는 1줄(10-09, 195) — 그것도 요일 루틴이
아니라 빌드 123 체크리스트에서 나왔다. 이번에 11-01 날짜 경계에서 찾은 210 을 더해, **10-07 뒤 루틴에서 찾은 것은 1건**이다.
요일별(월~토) 영역에서 찾았다고 적힌 것은 **0건**.

**2. 그 사이 08 피드백에는 20건이 들어왔다** (194~213). 어디서 나왔는지는 각 항목 제목 괄호의 접수 경위로 나눴다 — Claude 가 읽고 나눈 것이라 틀릴 수 있다.
